# @360gnh/core

Provider-neutral TypeScript domain engine behind [360GNH Knowledge Studio](https://github.com/nguyenduyhung1989/360GNH).

It provides source ingestion, timestamp-preserving chunking, local BM25 retrieval, citations, quizzes, study guides, smart clips, mind maps, and evidence-bound debate orchestration. The deterministic local model works without an API key; an optional OpenAI Responses adapter is included.

The package is at pre-release `0.1.x` status. See the repository [README](https://github.com/nguyenduyhung1989/360GNH#readme), [architecture](https://github.com/nguyenduyhung1989/360GNH/blob/main/docs/ARCHITECTURE.md), and [security policy](https://github.com/nguyenduyhung1989/360GNH/blob/main/SECURITY.md) before integrating it.
