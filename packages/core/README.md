# @360gnh/core

Provider-neutral TypeScript domain engine behind [360GNH Knowledge Studio](https://github.com/bke-edu/360GNH).

It provides source ingestion, canonical single-video YouTube boundaries, raw-to-edited transcript preservation, timestamp-aware chunking, local BM25 retrieval, citations, quizzes, study guides, smart clips, mind maps, evidence-bound debate orchestration, speech-safe text splitting, WAV composition, and process-local audiobook budgets. The deterministic local model works without an API key; optional provider adapters live behind small ports.

The package is at pre-release `0.1.x` status. See the repository [README](https://github.com/bke-edu/360GNH#readme), [architecture](https://github.com/bke-edu/360GNH/blob/main/docs/ARCHITECTURE.md), and [security policy](https://github.com/bke-edu/360GNH/blob/main/SECURITY.md) before integrating it.
