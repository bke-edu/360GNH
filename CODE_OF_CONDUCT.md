# Code of Conduct

360GNH is a technical community where disagreement is welcome and harassment is not.

## Expected behavior

- Critique claims, code, and evidence—not a person's identity or ability.
- State uncertainty and correct mistakes openly.
- Give enough context for others to reproduce a result.
- Respect privacy, licenses, and boundaries around unpublished work.
- Make room for contributors with different languages, backgrounds, and levels of experience.

## Unacceptable behavior

Harassment, threats, discriminatory remarks, sexualized attention, doxxing, deliberate exposure of secrets or personal data, sustained disruption, and retaliation are not tolerated in project spaces.

## Enforcement

Report conduct concerns privately to the maintainer through the contact method on the maintainer's GitHub profile. Do not open a public issue containing sensitive details. The maintainer may remove content, restrict participation, or ban an account when necessary to protect contributors and the project.

This policy applies to repository discussions, issues, pull requests, project chat, and public events where someone represents 360GNH.
